# 🛍️ MaryShop – Интернет-магазин

Учебный проект интернет-магазина с системой регистрации пользователей и административной панелью.  
Проект выполнен на **Vite + React**, с отдельным сервером для данных.  

## ✨ Основные возможности
- 👤 **Регистрация и вход** — поддержка обычного пользователя и администратора
- 🛒 **Товары** — карточки товаров с описанием и изображениями
- ⭐ **Избранное** — добавление и удаление товаров в список избранного
- 🛍️ **Корзина** — добавление и удаление товаров
- 🛠️ **Админ-панель** — управление товарами (добавление/редактирование, в разработке)
- 🎠 **Слайдеры/свайперы** для отображения товаров
- 📱 **Адаптивный интерфейс** (оптимизация под разные устройства)

## 🚀 Стек технологий
- [Vite](https://vitejs.dev/) + [React](https://react.dev/)
- [Tailwind CSS](https://tailwindcss.com/) (если используешь)
- [Material UI](https://mui.com/) (если подключен)
- Backend: локальный сервер (JSON Server / Express — уточнить)

## 📦 Установка и запуск
```bash
# Клонируем репозиторий
git clone https://github.com/username/MaryShop.git
cd MaryShop

# Устанавливаем зависимости
npm install

# Запускаем фронтенд
npm run dev

# Запускаем сервер (пример, если JSON Server)
npx json-server --watch db.json --port 3001
